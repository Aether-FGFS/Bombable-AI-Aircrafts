Bombable-AI-Aircrafts is Addon, for Flightgear Flight Simulator with installed Bombable-6.0 addon.
__________________________________________________________________________________________________

This package contain Aircrafts, with Dogfight Combat AI scenarios. 

Installation: 

To install this addon, copy and paste files from download into fgdata folder, following file structure. 
 Run AI Scenarios to use AI Airplanes and Helicopters in Dogfight.
